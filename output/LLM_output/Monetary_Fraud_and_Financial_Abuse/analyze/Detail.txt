The content of these messages is constructed by concatenating a value from the scheme with a `data` string.
*   **Trigger**: The behavior is triggered when the `RelatedContent.start()` method is called (as seen in `com.googleapi.cover.RelatedContent.setListeners`), which appears to be linked to user interaction with a "yes" button in a UI component that displays pricing information (e.g., `price_mf_1`, `price_mf_2`) and currency symbols (e.g., `R.string.rub`).
*   **Root Cause**: The application uses the `SmsManager.sendTextMessage` method to automate the sending of messages to multiple recipients without explicit user composition of the message content, which is a common technique in SMS fraud or premium rate service scams.
