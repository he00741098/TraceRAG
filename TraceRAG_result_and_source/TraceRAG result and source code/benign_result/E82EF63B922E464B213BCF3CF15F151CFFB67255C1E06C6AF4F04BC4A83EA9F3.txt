# 3. Privilege Abuse and System Exploitation  
## 3.1 Dynamic Code Handling via Reflection and Native Methods  
- **Code Path:** com.unity3d.player.ReflectionHelper  
  - **Analysis:**  
    The ReflectionHelper class contains a method (newProxyInstance) that creates dynamic proxies. Its InvocationHandler delegates all method invocations to a native method, nativeProxyInvoke, and uses nativeProxyFinalize during garbage collection. This redirection produces a dynamic call chain that, if manipulated, could allow unauthorized native code execution.  
  - **Call Chain Evidence:**  
    • newProxyInstance generates a dynamic proxy and assigns an InvocationHandler.  
    • Each intercepted method call is forwarded via the invoke method to nativeProxyInvoke.  
    • finalize subsequently calls nativeProxyFinalize during cleanup.
