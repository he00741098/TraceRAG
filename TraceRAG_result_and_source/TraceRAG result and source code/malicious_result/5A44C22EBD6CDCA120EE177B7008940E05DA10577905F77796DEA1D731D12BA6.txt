Across the analyzed reports, two behavior categories (Information Theft and Abuse, and Monetary Fraud and Financial Abuse) exhibited no evidence of malicious code patterns or suspicious call chains. In contrast, the Privilege Abuse and System Exploitation category demonstrated multiple instances of dynamic extraction, verification, and execution of native libraries from concealed directories. The code paths consistently show a call chain beginning in application startup methods—specifically within SuperApplication methods (such as attachBaseContext and onCreate)—leading to the invocation of native library loading and execution routines (e.g., in com.shell.NativeApplication). This dynamic native code management indicates concealed functionality designed to execute operations outside the standard Android framework, potentially facilitating unauthorized system-level actions.
